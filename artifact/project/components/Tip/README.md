# Tip

Consejo breve que enseña una función nueva o menos visible y se puede descartar (en Apple, *tip*, TipKit).

## Reglas de Apple
- Solo para funciones simples, de no más de tres pasos.
- Título orientado a la acción y **una o dos oraciones**. Nada promocional ni ajeno a lo que la persona está haciendo.
- Muéstralo solo a quien le sirve (quien ya usa la función no lo necesita) y con frecuencia moderada, por ejemplo uno cada 24 horas.
- Si hay un ícono asociado a la función, inclúyelo relleno. El ícono va en `control-on`.
- Una acción opcional que lleve directo al ajuste o al flujo.

## Qué aporta quien lo usa
- `title`, `message`, `icon`, `actionLabel`/`onAction` y `onDismiss`.
- Va dentro del flujo (tip en línea). Para señalar un control concreto sin texto largo, usa `Tooltip`.
