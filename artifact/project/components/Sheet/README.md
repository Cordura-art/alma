# Sheet

`Modal` que sube desde abajo en el teléfono y se centra desde tablet (`bp-md`), como las hojas de Apple. Mismas propiedades que `Modal`.

## Cuándo usarlo
Opciones relacionadas con lo que se está viendo: compartir, filtrar, elegir un medio de pago. En teléfono queda al alcance del pulgar.

## Aspecto
Barra de agarre arriba (solo decorativa), esquinas superiores `radius-panel` y respeta el área segura inferior del teléfono. Entra con `duration-moderate-02` + `easing-entrance-expressive`.
