# Motion

Muestra de las curvas y duraciones de ALMA (IBM Design Language) y de las tres recetas del movimiento de marca de Cordura. Úsala para elegir la combinación correcta; no es un componente para usar en productos.

## Cómo elegir
1. ¿Es interfaz de trabajo o un momento de marca? Productivo o expresivo.
2. ¿El elemento se mueve, aparece o se va? `standard`, `entrance` o `exit`.
3. ¿Qué tan grande es el cambio? De `duration-fast-01` a `duration-slow-02`.
4. ¿Es un momento de marca (portada, bienvenida, carga larga, logo)? Usa una receta de marca: `alma-brand-zoom`, `alma-brand-lines` o `alma-brand-morph`.

## Qué aporta quien lo usa
Nada: es una ficha de referencia. El botón «Repetir» vuelve a mostrar las recetas de marca.
