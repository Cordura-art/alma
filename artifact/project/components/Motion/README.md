# Motion

Muestra de las curvas y duraciones de ALMA (IBM Design Language) y de la coreografía de IBM Carbon para entradas de página. Úsala para elegir la combinación correcta; no es un componente para usar en productos.

## Cómo elegir
1. ¿Es interfaz de trabajo o un momento de marca? Productivo o expresivo.
2. ¿El elemento se mueve, aparece o se va? `standard`, `entrance` o `exit`.
3. ¿Qué tan grande es el cambio? De `duration-fast-01` a `duration-slow-02`.
4. ¿Entran varios elementos a la vez? Sigue la coreografía de Carbon: estructura, contenido, datos escalonados con `duration-stagger` (20 ms), acción principal y gráficos, con el total bajo 500 ms.

## Qué aporta quien lo usa
Nada: es una ficha de referencia. El botón «Repetir» vuelve a mostrar la coreografía.
