# Stepper

Contador de cantidad con botones − y + en píldoras de 56 px sobre `ui-01`, el color de contenedor (#F8FBFC en claro, azul noche en oscuro); el valor puede llevar un ícono de contexto.

## Qué aporta quien lo usa
- `min`, `max` y `value`/`onChange` (o `defaultValue`).
- `icon`: un ícono de la lista aprobada que explique qué se cuenta (`ticket` para pasajes).
- `label`: nombre accesible («Pasajeros»).

## Estados
- En el mínimo o el máximo, el botón correspondiente se deshabilita (`disabled-03`).
